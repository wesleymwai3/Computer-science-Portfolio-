### 2. CPU Scheduling Simulator
**Language:** Python

Simulates the Round Robin CPU scheduling algorithm.

**Features**
- Executes processes using a configurable time quantum.
- Displays the execution order in a Gantt chart.
- Calculates waiting time and turnaround time.
- Demonstrates CPU scheduling concepts in operating systems.

**Skills learned:** Process scheduling, loops, dictionaries, functions, and basic algorithm design.

**Future improvements:** Add Priority Scheduling and allow users to enter their own processes

### 3. Priority Scheduling Simulator
**Language:** Python

Implements non-preemptive Priority Scheduling for CPU process management.

**Features**
- Sorts processes by priority.
- Calculates waiting and turnaround times.
- Computes average waiting and turnaround times.
- Demonstrates CPU scheduling concepts.

**Skills learned:** Sorting, dictionaries, functions, and operating system algorithms.

### 4. Network Diagnostic Tool
**Language:** Python

A basic tool for checking system information, DNS resolution, and network connectivity.

**Features**
- Displays operating system information.
- Resolves hostnames to IP addresses.
- Attempts a ping connectivity test.
- Handles common lookup and timeout errors.

**Skills learned:** Python networking, DNS, sockets, subprocesses, and error handling.
